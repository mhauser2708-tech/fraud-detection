# Fraud Detection — Bank Transaction Dataset

## 1. Project Overview
This project focuses on detecting fraudulent transactions in banking data using and comparing various unsupervised machine learning methods. The goal is to explore how different approaches can identify unusual patterns and potential fraudulent activity without relying on pre-labeled data.

A key objective of the project was to strengthen my practical machine learning skills and gain hands-on experience with unsupervised learning techniques. By implementing, evaluating, and comparing different methods, I aimed to better understand their strengths, limitations, and practical applications in the context of fraud detection.
